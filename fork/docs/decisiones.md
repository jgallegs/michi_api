# Decisiones y cambios de reglas

- Toda decisión que afecte al fork se apunta aquí con fecha y con el rol de quien la toma.
- Las reglas de [reglas.md](reglas.md) solo cambian con una entrada en la tabla de cambios de reglas.
- Las entradas no se borran. Si una decisión se revierte, se añade otra nueva que lo diga.
